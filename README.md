# Weather App Using a Public API

## Project Title
Weather App Using a Public API

## Technologies Used
- HTML
- CSS
- JavaScript,
- API's

## Project Description
A responsive Weather App built using HTML, CSS, and JavaScript that fetches real-time weather information from a free public weather API.
Features
 -Search weather by city name
 -Display current temperature
 -Show humidity
 -Show wind speed
 -Display weather condition and icon
 -Loading indicator while fetching data
 -Error handling for invalid city names
 -Responsive design for mobile and desktop
## Setup Instructions
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. You can also use the Live Server extension in VS Code.
